Quick Start
1) Insure you have at least 3Mb of free disk space to hold the contents
   of this zip file.
2) Create a directory to hold these files listed above.
3) Extract the contents of this zip file into the destination directory
   using any compatible zip file extraction utility.
4) Delete the original zip file from your disk to save space.  (optional)


After self-decompression the vocabulary files included with this
product are in ordinary ASCII format with CRLF (ASCII 13/10)
delimiters.  The hyphenation marks are indicated with ASCII 165
character, which is significant in alphabetization.

Note that words that ought *not* to be hyphenated are included for
completeness.


Once decompressed, the vocabulary files may be viewed and used just
as any TEXT-type file might.
