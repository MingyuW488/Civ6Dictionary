# 文明 VI 英文学习 DEMO

Windows x64 桌面演示程序。用于验证《文明六》截图取词、本地英文 OCR、国内翻译接口的直连速度，并保存自己的原句与笔记。

当前为可搜索生词本版 v0.4.1，包含随程序提供的本地中英文词库。已支持 Windows 离线英文朗读，尚未包含复习算法和鼠标悬停自动取词。在线部分仍使用国内文本翻译接口。

## 可搜索的生词本（v0.4.0）

1. 在“词典详情”输入要收藏的英文单词 / 短语，点击“☆ 收藏到生词本”。收藏无需密钥或联网，保存本地中文释义、词性，以及第一页当前原句与笔记的快照。大小写及连续空格统一；同一个查询词不会重复收藏，也不会覆盖已保存的内容。词形（如 went 和 go）分别收藏，释义可来自原形。
2. 打开第五页“生词本”，输入英文、中文释义、词性、原句或笔记，稍停即筛选。留空显示全部。搜索覆盖数据库全部词条，每页最多显示 100 个词，支持翻页；百分号、下划线和引号作为普通字符处理。
3. 选中词条，下方可滚动查看完整释义、收藏时原句 / 笔记，以及同一词已有的全部关联笔记。双击词条或点击“查看词典”可重新查询，沿用现有联网补充选项。
4. 点击“导入已有笔记”，将全部历史笔记中的英文单词 / 最多六词的短语导入，包含列表前 500 条之外的记录。重复词合并，首次导入使用该词最新一条笔记作为快照；整句笔记仍在原页面。导入不会修改任何旧笔记。原笔记修改后，关联笔记搜索及详情在刷新 / 重选后使用最新内容，收藏时快照保留。
5. “移出生词本”只移除收藏，保留原笔记；需要时可重新收藏或导入。“导出全部 CSV”导出全部收藏词条及收藏时的原句 / 笔记，不受搜索和分页影响。关联笔记可在“本地笔记”另行导出。

生词本与原有笔记共用本机 learning.db，仅新增 vocabulary 表，旧记录保持兼容。没有本地释义的词也可收藏，释义留空；程序不保存接口返回的在线译文。运行新版前请关闭旧版，数据会沿用。


## 顶部音节分隔（v0.3.4）

词典详情中，单词下方、音标上方直接显示分隔，例如 production → pro · duc · tion，civilization → civ · i · li · za · tion。查询及朗读仍使用原单词，不包含分隔符。

本地分节表约 16.8 万条，按索引读取，无需联网。采用 Moby Hyphenator II 的书面分节数据，用于分段记忆，不标注重音，也不等同于所有口音中的语音音节边界；实际发音可结合音标和朗读。未收录或没有分隔的数据不额外显示，不用猜测规则强行拆分。短语和整句不作为一个单词拆分。

来源及作者公开领域授权说明见 data/syllables-source.json 与 data/MOBY-HYPHENATION-NOTICE.txt。该数据由 Grady Ward 于 2001 年授予 Public Domain；来源页面：https://www.gutenberg.org/ebooks/3204 。

## 整句填入查询栏（v0.3.3）

图片识别后，在识别文本下方点击“整句 / 整段填入查询栏”，即可将全部内容一次填入查询栏。若只想翻译其中一句，先在识别文本中选中该句，再点“选中文字填入”。识别文本可先手动修正，这两个按钮均使用当前文本。

填入时会合并换行及连续空白，保留标点；识别原文及笔记不受影响。查询栏支持自动换行和滚动。填入只改变查询内容，不自动调用接口；随后点击“查词 / 翻译”或按 Enter 才查询。

超过 2000 字符会提示先选择较短的句子，不会截断内容。未识别到文字、未选中内容时会提示，不清空已有查询。点击单词的原有功能继续可用。

## 修改已有笔记（v0.3.2）

1. 在“本地笔记”中选中一行，点击“修改笔记”；也可以双击打开详情后点击“修改”。
2. 修改单词/短语、游戏原句或个人笔记，点击“保存修改”。保存直接更新这一条记录，保留原来的创建时间，不新增重复笔记。
3. 点击“取消修改”会恢复到上次保存的内容；关闭窗口或按 Esc 会丢弃尚未保存的修改。已经成功保存的内容仍会保留。
4. 保存后可继续查看、再次修改，或点击“带回查词页”使用更新后的内容。关闭详情后，列表自动刷新并保持选中该条笔记。

单词/短语不能为空，原句和笔记可以清空。保存前如检测到其他窗口已修改或删除同一条笔记，会提示先复制需要保留的内容，再关闭详情、刷新列表后重试，不会直接覆盖较新的内容。数据库结构保持兼容，原有笔记可继续使用。

第一页“保存原句与笔记”仍用于新增记录；修改已保存的记录请使用上述入口。修改已有笔记不会覆盖第一页面尚未保存的输入内容。

## 点击发音（v0.3.0）

- 在“词典详情”点击“▶ 发音”，朗读当前查询的单词、短语或英文句子。
- 每条英文解释旁都有“朗读”按钮，可单独听这一条解释。
- 勾选“慢速”后再点击发音，会使用较慢语速；“停止”可中断朗读。连续点击会替换上一条，不会积累播放队列。
- 查询 went → go 等词形时，“发音”读 went，“原形发音”读 go。
- 使用本机 Windows 英文桌面语音合成，无需联网、API 密钥或额外接口费用。语音合成不是词典真人录音，具体音色取决于安装的英文语音。本机已检测到 Microsoft David 和 Zira 英文桌面语音，程序优先选择美式英文。
- 更换查询或退出程序时停止朗读。语音组件在首次点击时才加载；空闲时停止轮询。
- 其他电脑若没有兼容的英文桌面语音，界面会显示安装提示。实际出声使用 Windows 当前输出设备，音量受系统及应用混音器控制。

## 词典版新增内容

点击识别出的单词后，点“查词 / 翻译”或按 Enter，会打开“④ 词典详情”。也可以直接在词典详情顶部输入新词再按 Enter。

- 展示音标、词性、多项中文释义、英文解释及词形变化。
- “yield”会展示名词、及物动词、不及物动词等义项；“went”“denounced”等可以查到原形。
- 收录的部分短语也能离线查询。不同词条的解释完整程度不同；未收录的英文、词性会明确提示，不会生成猜测的解释。
- 本地查询不需要 API 密钥，不访问国外接口。共 770,611 条词条、56,943 条词形关联，词库约 67 MB，按 SQLite 索引读取，不整体加载到内存。
- 默认勾选“联网补充翻译”。已配置有道/百度时，先显示本地释义，再显示在线简明译文；尚未配置密钥时仍可正常查本地词条。
- 取消勾选后，单词/短语只查本地词库。完整句子仍使用在线翻译；句子翻译需要配置接口。
- 在线请求失败不会清除已显示的本地释义。
- “原句与笔记”可返回截图页；已有笔记数据库不变，旧版笔记可继续查看。关闭旧程序后打开新版，可以避免截图快捷键冲突。API 密钥仍需每次启动填写。

数据来源为 [ECDICT](https://github.com/skywind3000/ECDICT)，MIT 许可。来源版本与 SHA256 记录在 data/dictionary-source.json，许可在 data/ECDICT-LICENSE.txt。本地词典数据独立于有道/百度接口，不是保存接口返回结果。

本项目已保留随附词库、来源记录及许可；使用时无需重新下载或转换。src/data 与 app/data 是只读词库资源，个人笔记位于项目根目录 data/learning.db。

## 直接运行

打开项目中的 `app` 文件夹，双击 `Civ6EnglishDemo.exe`。必须保留整个文件夹中的 DLL、模型和其他文件。

此版本包含 .NET 运行时，使用时不需要安装 SDK。Tesseract 本机库需要 Microsoft Visual C++ 2015–2022 x64 运行库；开发机已验证可加载。如其他电脑报告本机 DLL 无法加载，请安装微软官方运行库：https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist

## 在 VS Code 中开发

用 VS Code 的“打开文件夹”打开本文件所在目录。

项目使用 C#、WPF、.NET 10、Tesseract 5.2、SQLite。首次交付的电脑上，SDK 和 NuGet 依赖已放在项目镜像根目录的 `work` 内，脚本自动使用；不会要求安装完整 Visual Studio。

- 菜单“终端 → 运行任务 → 运行 DEMO”：编译并运行。
- `Ctrl+Shift+B`：编译。
- “终端 → 运行任务 → 验证 DEMO”：执行离线自检。
- 安装推荐的 Microsoft C# 扩展后，按 F5 可调试。便携 SDK 位于项目根目录 `tools/dotnet`；本机 F5 配置已指向该目录。

本次环境中，C# 扩展自动安装未通过本机的扩展签名校验，因此没有关闭校验强行安装。编译和运行任务不依赖该扩展，均可使用；F5 调试需要在正常的 VS Code 环境中完成扩展安装。

PowerShell 中也可以运行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\run.ps1
powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1 -SelfTest
```

如果将源码移动到其他电脑，请先安装 [.NET 10 SDK](https://dotnet.microsoft.com/download/dotnet/10.0)，然后运行脚本恢复依赖。F5 配置中的 `DOTNET_ROOT` 可改为实际 SDK 目录，或在使用系统 SDK 时删除该配置项。依赖恢复可能需要访问 NuGet；应用日常运行不需要。

## 先测 OCR

1. 在第一个页签点击“打开示例”。它是一张生成的英文深底样例，不是实际游戏截图。
2. 查看文字、耗时和内存；点击单词会填入查询栏，不会自动发起网络请求。
3. 打开自己的游戏截图，拖动框选一段文字，松开后识别。图片选择界面为了方便框选会铺满桌面；结果预览保留原始像素。
4. 在游戏窗口化或无边框模式下，按 `Ctrl+Alt+D`，框选屏幕文字。Esc 或右键取消。若快捷键被其他软件占用，使用窗口里的按钮。
5. 结果不好时切换“放大 2 倍 / 自动适配明暗”，再次识别。识别完可以修正原句。

截图使用 GDI 屏幕捕获，不读取或修改游戏进程。独占全屏、HDR、特殊显卡覆盖层等可能影响截图，应在真实游戏中验证。多显示器不同缩放比例也需要在实际设备上验证。

OCR 在本地 CPU 上按需运行，不上传截图，不长期保存截图，每次识别后释放原生引擎。小选区会减少识别开销。窗口按 Esc 最小化，快捷键保持有效；关闭窗口会退出程序。

“引擎置信度”不是识别准确率。请人工挑选约 50 个真实目标词核对。日志记录识别结束前的内存快照，不是峰值；界面另显示引擎释放后的当前工作集，不能将两者当作完整的内存曲线。

## 再测在线接口

支持有道智云“文本翻译”和百度翻译“通用翻译”。先到官方平台注册、开通相应服务并取得应用 ID 与密钥：

- 有道文档：https://ai.youdao.com/DOCSIRMA/html/trans/api/wbfy/index.html
- 百度文档：https://fanyi-api.baidu.com/doc/21

1. 在“接口与测速”选择服务商，填写自己的 ID 与密钥。密钥仅在当前进程中使用，不写入配置、数据库或测试日志。
2. 关闭 VPN / TUN。程序设置 `UseProxy=false`，不使用 HTTP 系统代理；这无法绕过操作系统级 VPN，也不能证明流量一定从大陆直出。
3. 每行输入一个样本，点击“开始逐条测速”。最多 100 条，每条不超过 2000 字符，间隔至少 1.2 秒，单次超时 8 秒，无自动重试。
4. 查看成功率、成功请求的中位数和 P95。失败及取消单独记录，取消不进入成功率分母。
5. 导出 CSV。在你平时玩游戏的时段，以及另外两个时段重复测试。

测速包括连接、服务器处理和完整收到响应的时间；第一条包含冷连接开销，后续可能复用连接。每条都是实际调用，可能收费；没有应用缓存。成功率和延迟只代表这批请求，不能据少量样本推算长期服务保证。

服务商返回的译文只在查询区显示，不自动写入数据库。发音及完整词典数据不在本 DEMO 测试范围内。国内服务是直连候选，实际可达性、质量、开通资格、限额和计费以你的账户和网络实测为准。

## 笔记与数据

在第一个页签中填入词、原句和个人笔记，点击“保存原句与笔记”。第三个页签查看最近 500 条记录；CSV 导出包含全部记录。双击任意笔记行会打开详情窗口，完整查看单词、保存时间、游戏原句和个人笔记。原句及笔记分别自动换行、独立滚动，可选中复制，窗口可调整大小。关闭详情不会覆盖查词页上尚未保存的内容。如需取回内容，点击详情里的“带回查词页”；再次保存会新增一条，不覆盖旧记录。双击表头或空白处不会打开之前选中的笔记。

笔记数据库位置：项目根目录 `data/learning.db`。可点击“打开数据目录”。数据库保存个人笔记、原句、生词收藏及本地释义快照和测试元数据，不保存密钥、截图或在线译文。测试 CSV 含查询词，请按个人学习数据管理。退出程序后可备份整个数据目录。

高级用法：设置 `CIV6_DEMO_DATA` 可将数据目录改到自选位置；开发验证使用该变量将测试数据留在项目 `work` 下。v0.4.1 起默认数据目录跟随项目位置，不再写入 C 盘旧目录。

## 有道 NMT 返回 108 时

108 表示应用 ID 无效。程序第一栏对应请求参数 appKey，但它的含义是控制台的“应用 ID”；第二栏是同一个应用的“应用密钥”。请不要填服务实例 ID，也不要互换两项。

在有道控制台检查应用 ID 与密钥来自同一个应用、应用仍有效且接入方式为 API。当前应用需要绑定已开通的文本翻译（NMT）服务。110 对应服务绑定问题，202 对应签名校验失败，205 对应接入平台不一致，206 对应系统时间问题。

参考官方文档：https://ai.youdao.com/DOCSIRMA/html/trans/api/wbfy/index.html
