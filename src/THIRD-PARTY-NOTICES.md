# Third-party components

- Tesseract .NET wrapper 5.2.0, Charles Weld: Apache-2.0. Source: https://github.com/charlesw/tesseract . License included in TESSERACT-WRAPPER-LICENSE.txt. The wrapper distributes native Tesseract and Leptonica libraries and InteropDotNet. See the upstream project for native build attribution.
- Tesseract OCR: Apache-2.0. https://github.com/tesseract-ocr/tesseract
- English `eng.traineddata`, tessdata_fast: Apache-2.0. https://github.com/tesseract-ocr/tessdata_fast . License included in tessdata/LICENSE.
- Leptonica: BSD-style license. https://github.com/DanBloomberg/leptonica . Its license text is included in LEPTONICA-LICENSE.txt.
- Microsoft.Data.Sqlite.Core: MIT. https://github.com/dotnet/efcore
- SQLitePCLRaw.bundle_winsqlite3, provider.winsqlite3 and core: Apache-2.0. https://github.com/ericsink/SQLitePCL.raw . This application uses the Windows system SQLite library rather than shipping an additional SQLite native engine.
- .NET / WPF runtime: Microsoft .NET redistribution notices and license files are included in the Windows runtime folder.
- InteropDotNet: MIT. https://github.com/AndreyAkinshin/InteropDotNet
- ECDICT bilingual dictionary data: MIT, skywind3000. https://github.com/skywind3000/ECDICT . The pinned upstream revision, CSV checksum and build counts are in data/dictionary-source.json; license text in data/ECDICT-LICENSE.txt. This dataset is independent of the Youdao/Baidu translation services.

The sample images were generated for this demo and do not contain game assets.

- Moby Hyphenator II written word-division data, Grady Ward: Public Domain grant, January 2001. Source: https://www.gutenberg.org/ebooks/3204 . Converted to an indexed SQLite table; source checksums and author notice are in data/syllables-source.json and data/MOBY-HYPHENATION-NOTICE.txt.
